# 交付管线功能建设说明

## 一、建设目标

建设一个面向需求方和管理员的交付管线系统，让需求从提交、承接、推进、交付到复盘都能在线流转。需求方可以提交需求并查看本人相关需求进展，管理员可以统一维护交付台账、负责人视图、状态变化和交付效率数据。

## 二、核心功能

需求方侧支持注册或登录、提交新需求、查看本人提交或关注需求的进度，并用进度条展示当前交付阶段。

管理员侧支持完整台账查看、字段筛选、状态维护、负责人视图、台账日志和交付效率分析，并按角色控制不同管理员的操作范围。

系统侧支持获取渠道标准化、Sprint 周期管理、关键节点记录、用户满意度评价、交付效率分析，以及后续对接飞书登录、通讯录、Base 和消息通知。
